# Implementation history

Point-in-time reports from past work: what was built, what was verified, and
what was known to be unfinished. They are kept for context, not as
documentation of current behaviour — `docs/CURRENT_STATUS.md` and the code win
every disagreement.

These lived in the repository root until November 2026. New reports belong in
`docs/history/` (implementation notes) or `docs/audits/` (audits); the root is
reserved for `README.md`, `CHANGELOG.md`, `AGENTS.md`, `CLAUDE.md` and config.
